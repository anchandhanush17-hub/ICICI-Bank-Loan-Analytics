# ICICI Bank Loan Analytics Dashboard
## Project Overview
This project analyzes banking loan data using Microsoft Power BI. It provides insights into loan distribution, customer segments, disbursement trends, loan performance, and collections.
## Dashboard Pages
### Dashboard 1 - Loan Distribution & Disbursement
- Grade-wise loan distribution
- Product group-wise loan distribution
- Monthly disbursement trends
- Total interest and default loan count
### Dashboard 2 - Loan Performance Analysis
- Branch-wise performance
- Age group-wise loan distribution
- Loan status analysis
- Delinquent loan rate
- Default loan rate
- Loan maturity distribution
### Dashboard 3 - Loan Allocation Analysis
- Total loan amount
- Total loans
- Total collection
- State-wise loan allocation
- Religion-wise loan distribution
- Disbursement year analysis
## Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- Data Cleaning
- Data Visualization
- Business Intelligence
## Key Insights
- Analyzed loan distribution across customer grades.
- Identified monthly disbursement trends.
- Compared branch-wise performance.
- Evaluated default and delinquency rates.
- Analyzed state-wise loan allocation.
