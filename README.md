# ICICI Bank Loan Analytics Dashboard
## Project Overview
This project focuses on analyzing banking loan data using Microsoft Power BI. The dashboard provides insights into loan distribution, customer segments, loan performance, disbursement trends, and collections.
## Dashboard Pages
### Dashboard 1 - Loan Distribution & Disbursement
- Grade-wise loan distribution
- Product group-wise loan distribution
- Monthly disbursement trends
- Total interest
- Default loan count
- Delinquent client count
### Dashboard 2 - Loan Performance Analysis
- Branch-wise performance
- Age group-wise loan distribution
- Loan status analysis
- Delinquent loan rate
- Default loan rate
- Loan maturity distribution
### Dashboard 3 - Loan Allocation Analysis
- Total loan amount
- Total loans
- Total collection
- State-wise loan allocation
- Religion-wise loan distribution
- Disbursement year analysis
## Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- Data Cleaning
- Data Visualization
- Business Intelligence
## Key Insights
- Analyzed loan distribution across different customer grades.
- Identified monthly disbursement trends.
- Compared loan performance across branches.
- Evaluated delinquent and default loan rates.
- Analyzed loan allocation across different states.
- Examined loan status and maturity patterns.
